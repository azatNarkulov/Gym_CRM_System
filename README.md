# Gym CRM System

## Stack

| Layer       | Technology                       |
|-------------|----------------------------------|
| Language    | Java 25                          |
| Framework   | Spring Boot 3                    |
| Data Access | Spring Data JPA (Hibernate 6)    |
| DB          | PostgreSQL 16                    |
| Build       | Maven                            |
| Logging     | SLF4J + Logback                  |
| Testing     | JUnit 5, Mockito                 |
| API Docs    | Swagger / OpenAPI 3 (Springdoc)  |
| Monitoring  | Spring Boot Actuator, Prometheus |
